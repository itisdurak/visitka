# Сайт-визитка

Одностраничный сайт-портфолио: обо мне, навыки, проекты и контакты.
Сделан на чистом HTML, CSS и JavaScript — без сборщиков и внешних библиотек.

## Открыть

Просто открой `index.html` двойным кликом. Или через локальный сервер:

```bash
cd visitka
python -m http.server 8080
```

Затем открой http://127.0.0.1:8080

## Что можно поменять

- **Имя и текст** — в `index.html`, секции `hero`, `about`.
- **Контакты** — ссылки в секции `contacts` (сейчас там GitHub).
- **Проекты** — карточки в секции `projects`, ссылки `href`.
- **Цвета** — CSS-переменные в начале `styles.css` (`--accent`, `--paper` и т.д.).

## Проверено

- Нет ошибок JavaScript в консоли.
- Нет горизонтальной прокрутки на 375, 768 и 1280 px.
- Мобильное меню открывается и закрывается, ссылки ведут на существующие секции.
- Lighthouse: Accessibility — 100, Best Practices — 100, SEO — 100.
